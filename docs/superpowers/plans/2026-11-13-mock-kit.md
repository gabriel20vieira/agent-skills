# Plano — mock-kit

> Plano de implementação do plugin mock-kit: scripts e testes, kit no browser, shell, skill, registo no marketplace e experiência numa pasta descartável.

Spec: `docs/superpowers/specs/2026-11-13-mock-kit-design.md`. Executado inline.

## Ficheiros

```
plugins/mock-kit/
  .claude-plugin/plugin.json
  README.md
  skills/mock-kit/
    SKILL.md
    references/components.md, mock-checklist.md, variants.md, theme.md
    templates/mock.html, component.js
    assets/kit/kit.js, theme.css, versions.json, shell/*.js
    scripts/
      mock-kit.mjs        CLI: lê argumentos e chama os comandos
      kit.mjs             init, new, component, index, check, used, status, theme
      theme.mjs           tokens de CSS e de JSON, bloco @theme, theme.css
      serve.mjs           servidor estático 127.0.0.1
      shots.mjs           encontrar o browser, argumentos headless, capturas
      *.test.mjs          testes node --test
```

## Tarefas

1. **theme.mjs**, com testes: `tokensFromCss` (só `:root`, `:root, :host` e `@theme`; ignora
   `.dark` e media queries), `tokensFromJson` (plano, aninhado, `$value`), `themeBlock` (cores
   para `--color-*`, `--radius` para a escala do shadcn, `--font-*`), `renderThemeCss` (fundo
   branco, `color-scheme: light`).
2. **kit.mjs**, com testes: `init` (idempotente, `--from-css`, nunca por cima de componentes),
   `newMock` (slug válido, não sobrescreve, regista), `addComponent` (PascalCase, não sobrescreve,
   regista), `usedComponents`, `buildIndex`/`checkKit` (ficheiro em falta, nome repetido,
   componente sem uso como aviso, mock sem interação, bloco desatualizado), `setStatus`.
3. **serve.mjs**, com testes: responde, tipos MIME, recusa `..` (também codificado), só ouve em
   `127.0.0.1`.
4. **shots.mjs**, com testes das partes puras: procura do browser por variável de ambiente e
   caminhos conhecidos, argumentos headless, nomes dos ficheiros. A captura real é testada só
   se houver browser.
5. **Kit no browser**: `kit.js` (createMock, contexto, estado com «Repor», textos pt-PT e
   en-US) e o shell.
6. **Skill e referências**, README, manifesto, `plugin.test.mjs`.
7. **Registo**: marketplace, `CLAUDE.md`, `docs/guides/plugin-development.md`,
   `docs/architecture/overview.md`.
8. **Experiência**: pasta descartável, `init --from-css` do template, uma mock com dois
   componentes novos, `serve`, painel do browser (cliques, consola, telemóvel), `shots`.
9. **Checks** de `docs/settings.md`, PR, merge, apagar o branch.
